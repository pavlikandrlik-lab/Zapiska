# Začátek

Pokud je PM Tracker pro tebe nový, začni tady. Tato sekce ti vysvětlí jak se do
aplikace přihlásíš, kam jít po prvním přihlášení a jaké jsou společné UI vzorce
napříč aplikací (modaly, taby, ukládání).

## Cesta novým uživatelem

1. **[Přihlášení](prihlaseni.md)** — jak funguje přihlášení přes Active Directory
   a co potřebuješ mít, aby ses dostal dovnitř.
2. **[První kroky](prvni-kroky.md)** — co uvidíš po prvním přihlášení a kam jít
   dál.
3. **[Základní ovládání](ovladani-zakladni.md)** — společné UI vzorce: modaly,
   taby, AJAX uložení, klávesové zkratky.
4. **[Role a oprávnění — přehled](role-a-prava-prehled.md)** — co můžeš a co
   ne; co dělat, když nevidíš tlačítko.

## Co je dobré vědět hned

- PM Tracker je **vnitřní intranet aplikace**. Není přístupná z veřejného
  internetu, autentifikace probíhá automaticky přes tvůj firemní účet.
- **Záznam v aplikaci** musíš mít — samotná existence účtu v AD nestačí.
  Pokud se po přihlášení dostaneš na chybovou stránku 401/403, kontaktuj
  administrátora aby tě založil v `dbo.osoby`.
- **Co můžeš dělat** závisí na rolích, které ti přiřadí admin. Bez role
  uvidíš jen čtení, mutace (vytvořit, upravit, smazat) jsou skryté.
