# Profil

Profil je tvoje osobní stránka. Ukazuje **co o tobě aplikace ví** a **co můžeš
dělat**. Slouží také jako vstup pro tvoje uživatelské preference (téma, výchozí
volby).

## Co tady najdeš

- **Tvoje identita** — jméno, login, organizační celek (přebrané z Active Directory)
- **Tvoje role** — globální i per-projekt
- **Tvoje efektivní práva** — výpis permission keys (rozbalených z rolí)
- **Tvé preference** — téma, výchozí editor, výchozí formát tisku

## Sub-stránky

- [Moje práva](moje-prava.md) — detail efektivních permission keys
- [Uživatelské nastavení](nastaveni-uzivatele.md) — preference, téma, reset uložených voleb

## Co tady **neuděláš**

- **Změnit si role / přiřazení do projektů** — to spravuje admin v
  [Nastavení → Uživatelé × role](../nastaveni-administrace/uzivatele-role/). Pokud chceš
  jinou roli, kontaktuj admina.
- **Změnit jméno / email** — atributy se synchronizují z AD. Změna se musí
  udělat v AD, pak proběhne sync a propíše se sem.
- **Změnit heslo** — heslo PM Tracker neukládá. Heslo měň v Active Directory
  / Windows.

## Pro koho

Pro každého přihlášeného uživatele. Profil je v navigaci vždy viditelný (zpravidla
v pravém horním rohu pod tvým jménem nebo iniciálami).
