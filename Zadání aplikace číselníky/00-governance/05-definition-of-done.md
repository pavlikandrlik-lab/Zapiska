# Definition of Done

## Blok je hotový, když

- [ ] Build končí s **0 chybami a 0 varováními**.
- [ ] Kompletní sada Unit testů běží zeleně — spuštěna a výsledek nahlášen.
- [ ] Nové chování má **deterministický regresní test, který před opravou selhal**.
- [ ] Aplikace je po bloku spustitelná a ručně vyzkoušitelná.
- [ ] Dotčená dokumentace je aktualizovaná ve stejném bloku.
- [ ] Otevřené dluhy jsou zapsané do tabulky „Přenášené dluhy" v plánu.
- [ ] Nic není zacommitováno — commit dělá zadavatel po ruční verifikaci.
